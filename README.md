/**
 * error handling 3 types
 * 1. uncaughtException error
 *    - This error occurs when an exception is thrown but not caught anywhere in the code.
 * 2. unhandledRejection error
 *   - This error occurs when a promise is rejected but there is no catch block to handle the rejection.
 * 3. signal termination error
 *  - This error occurs when the process receives a termination signal (like SIGINT or SIGTERM).
 */
